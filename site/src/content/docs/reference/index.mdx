## Inspect what the release actually advertises

The [exact contract explorer](../generated/contract-explorer.html) is generated through the production registration path in credential-free catalog mode. It includes tools, schemas, annotations, prompts, resources, completion bindings, plan-review app evidence, risk classes, and contract digests. It cannot execute a tool, contact Discord, read a token, reveal policy IDs, open the Gateway, export telemetry, or create an activity record.

<Aside type="note" title="Source of truth">

Generated pages link back to their canonical Markdown source. If navigation and source ever disagree, generation or validation fails rather than publishing an independent copy.

</Aside>
